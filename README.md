Virtual Foundation Shade

Virtual Foundation Shade is a machine-learning–based application designed to help users identify their ideal foundation shade using image analysis. The system processes user-selected regions of facial images to detect skin tones and recommend suitable makeup shades with improved accuracy.

✨ Key Features

Skin Region Selection: Allows users to select specific regions of the face for more accurate shade detection.

Skin Tone Detection: Uses image-processing techniques to extract dominant skin tone values.

Foundation Shade Recommendation: Maps detected skin tone to the closest matching foundation shade from a predefined dataset.

User-Friendly Interface: Simple and interactive design suitable for both technical and non-technical users.

Automated Workflow: End-to-end process from image upload to shade suggestion.

📌 Project Objective

The main goal of this project is to make the foundation-matching process more precise and inclusive by leveraging AI and image processing. It aims to reduce guesswork in cosmetics shade selection and improve user confidence in choosing products suited to their skin tone.
